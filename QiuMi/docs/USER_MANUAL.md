# 嫂子模拟器 · 使用说明

## 欢迎

欢迎来到"嫂子模拟器"——一款沉浸式体验内娱时代峰峻男爱豆秘密女友日常的文字模拟游戏。

你将扮演一位与养成系偶像维持秘密恋情的女性，在聚光灯照不到的角落，体验浪漫、压力、抉择与冒险。

---

## 快速开始

### 第一步：进入游戏

打开游戏后，你会看到标题画面。点击 **"开始新游戏"** 进入角色创建。

如果你之前玩过并导出了存档，可以点击 **"读取存档"**，将之前保存的文本粘贴进去继续游戏。

### 第二步：创建你的角色

角色创建分为四个步骤：

**1. 填写基本信息**
- 输入你的姓名
- 输入男友对你的称呼（如：宝宝、亲爱的）
- 输入年龄（需满18岁）

**2. 选择你的身份**

共有八种身份可选，不同身份会影响你们相遇的方式：

| 身份 | 相遇场景 |
|------|---------|
| 粉丝 | 签售会、演唱会、接送机 |
| 经纪人 | 工作交接、日常行程安排 |
| 演员/歌手同行 | 片场、打歌节目、颁奖典礼 |
| 练习生 | 练习室、公司食堂 |
| 造型师 | 化妆间、造型工作室 |
| 素人 | 咖啡店、街头偶遇 |
| 制作人 | 录音棚、制作会议 |
| 财阀背景 | 慈善晚宴、品牌活动 |

**3. 选择你的男友**

从时代峰峻旗下22位男爱豆中选择一位：
- TFBOYS（3人）：王俊凯、王源、易烊千玺
- TNT时代少年团（7人）：马嘉祺、丁程鑫、宋亚轩、刘耀文、张真源、严浩翔、贺峻霖
- TOP登陆少年组合（5人）：朱志鑫、张泽禹、张极、左航、苏新皓
- TF-ing厂牌（5人）：穆祉丞、邓佳鑫、童禹坤、张子墨、黄朔
- Solo艺人（2人）：张峻豪、余宇涵

选择后，输入你对他的称呼（如：欧巴、哥哥）。

**4. 确认信息**

系统会随机生成三项隐藏设定：
- 他对你的感情基础（真心相爱、各取所需、利益交换等）
- 他的隐藏性格缺陷（海王、渣男、回避型等）
- 不能公开恋情的原因

这些设定将在游戏过程中逐步揭晓，请保持耐心。

点击 **"开始游戏"** 进入前置剧情。

### 第三步：阅读前置剧情

系统会根据你的身份生成一段专属的相遇故事。阅读完毕后，点击 **"确认并开始游戏"** 进入游戏主循环。

## 游戏玩法

### 游戏流程

游戏以"回合"为单位推进。每个回合代表一段时间（可能是几小时、一天或几天）。

每个回合包含三个阶段：

#### 阶段一：信息同步

回合开始时，手机会自动收到各种消息：
- 微博热搜推送
- 男友发来的微信消息
- 朋友或家人的消息
- 陌生短信（可能是骚扰或威胁）
- 未接来电

这些消息会以顶部横幅通知的形式弹出，点击即可消除。

#### 阶段二：自由行动

你拥有 **3个行动点**，可以从以下行动中选择：

| 行动 | 说明 |
|------|------|
| 查看手机 | 打开手机桌面，可以依次浏览各个应用 |
| 处理工作 | 专注工作，暂时忘记烦恼 |
| 休息一下 | 躺下休息，享受安静时光 |
| 逛街购物 | 去商场逛逛，看到好看的衣服会想起他 |
| 运动健身 | 去健身房出汗，神清气爽 |
| 学习充电 | 静下心来学习，提升自己 |
| 探班男友 | 尝试去片场或公司看他 |
| 约朋友 | 和朋友吃饭聊天 |

你可以多次选择同一个行动，也可以混合选择。行动点用完后，点击 **"结束自由行动"** 进入事件阶段。

#### 阶段三：随机事件

系统会自动触发与你的恋情相关的各种事件。事件类型包括：

- **约会事件**：车内秘密见面、家中相聚、国外旅行等
- **事业事件**：他发新歌、绯闻风波、获奖等
- **危机事件**：私生饭跟踪、公司施压等
- **生活事件**：闺蜜聚会、工作机遇等
- **娱乐圈事件**：颁奖典礼、其他明星恋情曝光等

每个事件都会提供 **四个选项（A/B/C/D）**，你必须选择其中一个才能继续。选项仅描述你的行动或对话，不会提示后果——你需要自己判断。

如果一回合触发了多个事件，它们会依次出现，你需要逐个处理。

## 手机使用指南

手机是本游戏的核心交互界面。在自由行动阶段选择"查看手机"，或在桌面点击应用图标，即可进入对应应用。

### 手机桌面

桌面排列着12个应用图标。底部Dock栏固定了四个常用应用：电话、短信、微信、微博。

应用图标右上角的红色数字表示未读消息数量。

### 各应用说明

**微博**
- 查看热搜榜单
- 浏览推荐帖子
- 了解饭圈动态和八卦

**微信**
- 查看聊天列表
- 点击联系人进入对话界面
- 可以输入并发送消息（模拟聊天体验）
- 男友的消息会置顶显示

**T-FAMILY（时代峰峻官方社区）**
- 查看官方公告
- 浏览成员发布的动态
- 了解团体最新行程

**抖音**
- 刷短视频信息流
- 可能刷到男友的直拍、粉丝剪辑
- 也可能刷到八卦分析视频

**小红书**
- 双列笔记流浏览
- 查看偶遇帖、穿搭分享
- 可能看到关于"嫂子"的分析帖

**B站**
- 视频推荐列表
- 舞台直拍、混剪视频
- 微表情分析等粉丝向内容

**QQ**
- 群聊列表（家族群、同学群、站姐群）
- 好友列表

**网易云音乐**
- 歌单推荐
- 好友动态（他分享了什么歌）

**短信**
- 查看收到的短信
- 可能包含快递通知、银行信息
- 也可能收到陌生号码的威胁短信

**电话**
- 查看通话记录
- 显示未接来电

**相册**
- 照片网格展示
- 底部有私密相册入口（需要密码）

**设置**
- 导出存档：将当前游戏进度保存为文本
- 读取存档：粘贴之前保存的文本继续游戏

### 返回桌面

在任何应用中点击左上角的 **"← 返回"** 按钮，即可回到手机桌面。

## 重要系统说明

### 亲密互动

每4回合会出现一次亲密机会。届时你需要选择是否采取安全措施：
- 采取措施：怀孕概率极低（约1%）
- 不采取措施：怀孕概率较高（约40%）

### 怀孕

如果怀孕，你会陆续出现身体异常症状。届时需要：
1. 购买验孕棒检测（90%准确率）
2. 决定是否告知男友
3. 去医院确认（100%准确）
4. 与男友商讨去留（最终决定权在你）

### 关系变化

随着游戏推进，你们的关系可能经历：
- 争吵与误会
- 分手与复合
- 求婚（30回合后可能触发）
- 结婚（几乎必然需要隐婚）
- 离婚

他的隐藏性格会在20回合后通过事件细节逐步显现，请留意剧情中的蛛丝马迹。

## 存档管理

### 保存进度

1. 在手机桌面打开 **"设置"** 应用
2. 点击 **"导出存档"**
3. 点击 **"复制到剪贴板"**
4. 将复制的文本粘贴到安全的地方（如备忘录、文档）

### 读取进度

1. 在标题画面点击 **"读取存档"**，或在设置应用中点击 **"读取存档"**
2. 粘贴之前保存的存档文本
3. 点击确认
